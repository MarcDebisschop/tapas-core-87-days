# 87 Days — Built with Perplexity Computer

A single-page account of what was built for TaPas CORE / TaPasCity with Perplexity Computer
between 8 May and 7 September 2026. Static site: HTML, CSS and one JavaScript file, no build step.

- Entry point: `index.html`
- Styles: `style.css`
- Behaviour (lightbox, theme toggle, scroll reveal): `main.js`
- Images: `assets/g/`

Deployed on Render as a static site with publish directory `.` and an empty build command.
See `render.yaml`.
