# Tapas CORE in 87 Days — Build in the demo ICT platform

A single-page account of what was built for TaPas CORE / TaPasCity in an AI build environment.
This is the focused edition: it covers the assessment platform, the instrument family, the stories,
the brand and the working methods only. Unrelated products built in the same period are not included.

The record covers 8 May to 7 September 2026. Static site: HTML, CSS and one JavaScript file, no build step.

- Entry point: `index.html`
- Styles: `style.css`
- Behaviour (lightbox, theme toggle, scroll reveal): `main.js`
- Images: `assets/g/`

Deployed on Render as a static site with publish directory `.` and an empty build command.
See `render.yaml`.
